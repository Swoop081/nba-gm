# NBA GM

Mobile-first NBA front-office simulation for private use, designed for GitHub Pages.

## v0.1 foundation
- 30-team franchise selection
- iPhone-first graphical UI
- persistent local career save
- dashboard and league-wire foundation
- NBA.com CDN player portrait support
- roster/player rating model scaffold
- Team / League / GM navigation

Next layers: complete current roster/contract database, simulation engine, trades, free agency, draft, development/decline, injuries, milestones and infinite-season history.
